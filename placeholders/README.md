# Placeholder assets for index2.html

Every file in this folder is a labelled stand-in. Swap it for the real
artwork (keep the file name, or update the `src` in `index2.html`).

| File | Used in | Replace with |
| --- | --- | --- |
| `bottle-front.svg` | Pour section, main bottle | Transparent PNG cut-out of the upright bottle (with glow). |
| `bottle-flipped.svg` | Pour section, shown after the flip | Transparent PNG of the bottle with the chaser side up, authored upright. |
| `instructions-shot.svg` | Pour section, "tilt for the vodka" phase | "Take the shot" instruction artwork. |
| `instructions-chaser.svg` | Pour section, "tilt for the chaser" phase | "Flip for the chaser" instruction artwork. |
| `what-is-a-kickback.svg` | Pour section intro overlay | Big headline artwork ("What is a Kickback?"). |
| `map-preview.svg` | Store finder card | Static map screenshot, or replace the `<img>` with an embedded map. |
| `hero-loop.mp4` (not included) | Hero on mobile | Short looping product video. On desktop the hero image slot is where a 3D / WebGL bottle scene would go. |

The pour streams themselves are inline SVG in `index2.html` and need no asset.
